# RapidResolve

A console designed to help **Help Desk technicians** quickly access and use standardized message templates for efficient incident ticket handling.

## Overview

RapidResolve is a lightweight tool that allows technicians to streamline communication with users by providing **ready-to-use, standardized response templates**. It reduces response time, improves consistency, and ensures clear communication across all incident handling processes.

  <img src="https://i.postimg.cc/qv0XtHWp/Rapid-Resolve.png" alt="Rapid Resolve">
</p>

## Key Features

- Quick access to incident response templates
- Standardized messaging for consistency
- Designed for Help Desk & IT Support teams

## Attention

This project requires **basic knowledge of PowerShell** in order to fully customize and extend the console.

To effectively use and maintain this tool, you should be familiar with:
- Variables and string manipulation in PowerShell
- Script structure and functions
- Basic debugging in a PowerShell environment

Without these fundamentals, customizing or adding new messages to the console may be difficult.

To run the script, you may need to use the following command in PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File ".\RapidResolve.ps1"
```
